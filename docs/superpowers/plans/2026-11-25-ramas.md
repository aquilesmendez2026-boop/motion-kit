# Ramas: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un relato de página `ramas`: el Hilo de fondo con un tronco que siempre llega abajo y ramas que se separan y se apagan con una chispa al chocar con el borde.

**Architecture:** Un trazado puro (`trazarRamas`) calcula el tronco y las ramas a partir del ancho, el alto, el alto visible y la semilla. Un componente que se baja aparte (`Ramas.tsx`) los dibuja en un SVG detrás de los bloques, con `stroke-dashoffset` atado a `scroll(nearest)` como el Hilo. `PaginaRelato` ya mide ancho y alto para el Hilo: se reusa.

**Tech Stack:** React 19 + TS, CSS con `animation-timeline: scroll()`, `node:test` (`node scripts/pruebas.mjs`), Playwright (`scripts/verificar-hilos.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-25-ramas-design.md` (con su «Cambio del 25-11-2026», que manda sobre lo de antes)

> **Cambio del 25-11-2026:** las ramas son de dos clases (chocan con un bloque o se juntan con el tronco al fondo), con grosor, opacidad y tono propios, y `trazarRamas` recibe las cajas de los bloques con fondo (`bloques`). Las pruebas de la Task 1 y la parte visual se ajustan a eso; lo demás del plan sigue igual. Se trabaja en la rama `ramas`.

- Color: `var(--mk-acento,var(--lm-acento,#e4572e))`.
- Archivo aparte; `motion-kit/pagina` bajo 17 KB (`npm run peso`).
- Contrato de página: `ramas` se suma a `relatoPagina`, solo agrega (`npm run contrato`).
- Comentarios y textos en español de Chile, frases cortas. Sin commits hasta que Aquiles lo pida.
- No tocar `src/` ni `demo/` mientras corre una prueba visual.

## Review Focus

1. Página corta (alto ≤ un alto visible): igual van 3 ramas, todas dentro de la página, y el tronco llega abajo.
2. Página angosta (280 px) y ancha (1200 px): el tronco no se sale; cada rama termina exacto en x = 0 o x = ancho.
3. Ancho o alto en 0 o `NaN`, vista en 0: no hay ramas y nada lanza (en vez de dividir por cero).
4. La página cambia de alto (una foto que carga): las ramas se recalculan (lo hace `useMedidas` de `PaginaRelato`; probar en la parte visual alargando el texto con `hilo-crece`).
5. Una página de La Mente con franjas opacas: el dibujo queda detrás y solo asoma entre bloques; las capturas tienen que mostrar que en la vitrina se nota.

### Task 1: El trazado de las ramas (puro)

**Files:**
- Create: `src/relatos/ramas/trazar-ramas.ts`
- Test: `pruebas/ramas.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export interface TrazoRama { d: string; puntos: { x: number; y: number }[]; desde: number; hasta: number }
  export interface Rama extends TrazoRama { lado: -1 | 1; choque: { x: number; y: number } }
  export function trazarRamas(ancho: number, alto: number, o: { vista: number; semilla: string }): { tronco: TrazoRama | null; ramas: Rama[] }
  ```
  `desde`/`hasta` van de 0 a 100: la parte del scroll en que se dibuja. El tronco va de 0 a 100 (como el Hilo); una rama parte en el punto del scroll en que el tronco pasa por donde nace y avanza al mismo paso que el tronco (largo de la rama / largo del tronco × 100), con `hasta` ≤ 100. La chispa aparece en `hasta`.

- [ ] **Step 1: Escribir las pruebas** en `pruebas/ramas.test.ts`:
  - `ramas: el tronco va de arriba al fondo sin salirse` — para anchos 280, 390, 1200 y altos 600, 3000, 9000 (vista 800): primer punto en y = 0, último en y = alto, todo x dentro de [12, ancho − 12]; `desde` 0 y `hasta` 100.
  - `ramas: cada rama nace en el tronco y termina justo en un borde, alternando el lado` — nace a menos de 0,5 px del tronco; su último punto tiene x = 0 (lado −1) o x = ancho (lado 1) exacto, y `choque` es ese punto; lados alternan; cada rama baja (su y final > la inicial) y queda dentro de [0, alto].
  - `ramas: entre 3 y 7 según el alto` — alto 600 → 3, 3000 → 4 o más, 20000 → 7 (vista 800).
  - `ramas: cada rama se dibuja cuando el tronco pasa por donde nace` — `desde` de la rama = la parte del tronco ya dibujada en su punto de nacimiento (± 0,5); `hasta` > `desde`, ≤ 100; las ramas en orden de `desde`.
  - `ramas: la misma semilla da lo mismo; otra, otra cosa; y las medidas raras no la botan` — igualdad por `JSON.stringify`; con ancho/alto/vista en 0, `NaN` o negativos: `{ tronco: null, ramas: [] }`; todos los números finitos (recorrer el objeto, no `JSON.stringify`, que vuelve `NaN` en `null`).

Las ramas nacen en alturas parejas entre el 8 % y el 85 % del alto; cuántas: `clamp(round(alto / vista), 3, 7)`. Cada rama: curva hacia afuera y abajo (bajada de 60 a 160 px según la semilla) que termina en el borde de su lado. Camino `d` con la `suave` de `src/relatos/hilos/geometria.ts` (importarla está bien: es chica y ese archivo no arrastra nada).
