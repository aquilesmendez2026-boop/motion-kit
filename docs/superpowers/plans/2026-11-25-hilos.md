# Hilos: plan de construcción

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** tres relatos de página nuevos (`rulos`, `hebras`, `figura`): un hilo que serpentea con rulos, se abre en
hebras en los bloques con tarjetas, se junta, y al final dibuja la figura del rubro.

**Architecture:** una función pura arma el trazado (tramos SVG con su tramo del scroll) a partir de medidas de la
página; una pieza que se baja aparte mide el DOM, llama a la función y dibuja un SVG; el navegador lo dibuja atado al
scroll (`stroke-dashoffset`, `offset-distance`, `opacity`). Después de medir no corre código.

**Tech Stack:** React 19, TypeScript, CSS con `animation-timeline: scroll(nearest)`, Playwright para lo visual.

**Spec:** `docs/superpowers/specs/2026-11-25-hilos-design.md` (aprobado por Aquiles el 25-11-2026: «si a todo»).

**Ejecución:** nativa, en esta sesión; sin commits hasta la orden de Aquiles; revisión final en Opus (local).

## Global Constraints

- Sin dependencias nuevas. Sin `Math.random` (semilla de `src/efectos/semilla`). Español de Chile, frases cortas.
- Lo único que se anima: `stroke-dashoffset`, `offset-distance` y `opacity` (la excepción que ya tiene el Hilo).
- Con la página quieta no se pide ningún cuadro. El `hilo` de hoy no cambia.
- El hilo nunca pasa sobre un texto, una foto, una tarjeta ni un botón (holgura de 2 px).
- Pesos (gzip): `motion-kit/pagina` no sube más de 0,3 KB al cargar (hoy 15,5; tope 17). El archivo aparte de los
  hilos, a lo más 5 KB.
- Niveles: completo con scroll nativo, todo; liviano o sin scroll nativo, el hilo entero y quieto, sin luces; quieto,
  sin hilo (con `figura`, la figura quieta en su remate).
- No se editan `src/` ni `demo/` mientras corre una prueba visual. Un proceso pesado a la vez.
- Solo se corren las pruebas visuales que el cambio toca (`relatos`, `hilos` y las de `dedo` que comparten página).

## Review Focus

1. Una página real de La Mente: franjas pegadas sin espacio y con relleno; ¿el hilo se ve en toda la bajada?
2. Contenido que cambia de alto después de montar (fotos que cargan, acordeones): el hilo se vuelve a trazar y no
   queda sobre el contenido nuevo.
3. La página dentro de un contenedor con cosas arriba y abajo (el scroll total no es el alto de la página): la punta
   del hilo sigue a la vista.
4. Un bloque que entra con su relato (`translate`, `scale`): el hilo se mide contra su lugar final, no a medio camino.
5. Fondos: franja del color del acento, fondos con degradado o imagen (sin color que leer): el hilo se distingue.

**Interfaces (produces):**

```ts
// catalogo.ts
export type FiguraId = "taza" | "hamburguesa" | "plato" | "navaja" | "tijera" | "huella" | "pesa" | "lapiz" | "bolsa" | "corazon" | "estrella";
export const FIGURA_IDS: FiguraId[];
/** La figura de un rubro (`RubroId` de los encabezados); la estrella si no se conoce. */
export function figuraDeRubro(rubro: unknown): FiguraId;

// hilos/figuras.ts
/** Un solo trazo (una sola orden `M`), dentro de una caja de 0 a 100. */
export const CAMINOS: Record<FiguraId, string>;
/** Los puntos de una figura, para probarla y para pegarla al hilo: en la caja de 0 a 100. */
export function puntosDeFigura(id: FiguraId): Punto[];

// hilos/trazar.ts
export interface Punto { x: number; y: number }
export interface Caja { izquierda: number; arriba: number; ancho: number; alto: number }
export interface BloqueMedido { caja: Caja; contenido: Caja | null; tarjetas: Caja[]; fondo: string; texto: string; tira: boolean }
export interface Medidas { ancho: number; alto: number; vista: number; recorrido: number; arriba: number; bloques: BloqueMedido[] }
export type TipoHilo = "rulos" | "hebras" | "figura";
export interface OpcionesHilo { tipo: TipoHilo; semilla: string; figura?: FiguraId; acento: string }
export interface Tramo { d: string; puntos: Punto[]; desde: number; hasta: number; clase: "tronco" | "hebra" | "figura"; color?: string }
export interface Nudo { x: number; y: number; en: number; clase: "nudo" | "puntada" }
export interface Trazado { tramos: Tramo[]; nudos: Nudo[] }
export const CANAL_MINIMO = 10, ORILLA_MAXIMA = 14, RULO_MINIMO = 8, RULO_MAXIMO = 18, CRUCE_CON_RULO = 24, HEBRAS_MAXIMAS = 5, REMATE = 140, HOLGURA = 2;
/** El porcentaje del scroll (0 a 100) en que el punto de altura `y` pasa por el 60 % de la vista. */
export function scrollDe(y: number, m: Medidas): number;
/** Razón de contraste entre dos colores CSS (`rgb()`, `rgba()` o `#hex`); 21 si alguno no se entiende. */
export function contraste(a: string, b: string): number;
export function trazarHilos(m: Medidas, o: OpcionesHilo): Trazado;
```

`puntos` son muestras del mismo camino que `d` (cada 8 px o menos): con ellos se prueba que el hilo no pisa contenido.
`d` pasa suave por esos puntos. El remate de `figura` va de `m.alto − REMATE` a `m.alto`.

  4 tarjetas, foto de lado a lado sin relleno, lista de 1 columna con 3 tarjetas) y estas pruebas:
  - `figuras: once, de un solo trazo y dentro de su caja` (cada `CAMINOS[id]` tiene una sola `M`; sus puntos, de 0 a 100).
  - `figuraDeRubro: cada rubro tiene su figura y lo desconocido es la estrella`.
  - `scrollDe: va de 0 a 100, crece con la altura y cuenta lo que hay sobre la página`.
  - `rulos: una cadena continua, un tramo por bloque, que alterna el lado` (cada tramo parte a ≤ 1 px de donde terminó
    el anterior, salvo puntada; `desde ≤ hasta`; en orden; el último termina en 100).
  - `rulos: el hilo nunca pisa el contenido ni una tarjeta` (ningún punto dentro de una caja de contenido o tarjeta

  - `hebras: una tira que se desliza o menos de 2 tarjetas no abren el hilo`.
  - `color: sobre un fondo parecido al acento, el tramo lleva el color del texto` (`contraste < 1,6`).
  - `figura: el último tramo es la figura, dentro del remate, y termina en 100`.
  - `semilla: misma semilla, mismo trazado; otra semilla, otro`.
  - `medidas raras no lo botan` (sin bloques; un bloque más alto que la vista; recorrido 0; ancho 320; `NaN`).
