# Código de terceros

Aquí se registra todo código copiado o adaptado de otros proyectos, junto con su
licencia. La licencia MIT exige conservar el aviso de copyright original.

Por ahora **no hay código de terceros**: los efectos de esta librería están
escritos desde cero.

## Cómo agregar una entrada

```
### Nombre del componente
- Origen: URL del repositorio o página
- Licencia: MIT / Apache-2.0 / otra
- Copyright: © año autor
- Qué se tomó y qué se modificó:
```

## Reglas del proyecto

- Solo se copia código con licencia MIT o Apache-2.0.
- No se copia nada de planes Pro o de pago.
- No se incluye código de GSAP dentro de la librería (su licencia prohíbe
  redistribuirlo); si se usa, va como dependencia opcional.
- Con React Bits (MIT + Commons Clause) no se copia código tal cual.
